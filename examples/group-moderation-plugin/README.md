# 群成员禁言管理

面向 QQ 群主和管理员的托管插件。机器人必须已经在目标群中被设置为管理员。

## 命令

- `/禁言 @成员 30s`：禁言 30 秒。
- `/禁言 @成员 10m`：禁言 10 分钟。
- `/禁言 @成员 2h`：禁言 2 小时。
- `/禁言 @成员 1d`：禁言 1 天。
- `/禁言 @成员`：使用安装配置中的默认时长。
- `/解禁 @成员`：立即解除禁言。
- `/禁言状态`：查询当前群被禁言的成员数量。

时长单位同时支持 `秒`、`分钟`、`小时`、`天`。命令需要在群聊中 @ 机器人触发，并且每次只能 @ 一名目标成员。

## 安全约束

- 仅 QQ 事件中 `member_role` 为 `owner` 的群主，或安装配置允许的 `admin` 管理员可以执行命令。
- 目标必须是 QQ 事件 `mentions` 中的一名普通成员。
- 不支持禁言群主、管理员、机器人或命令发送者本人。
- 不保存群 OpenID、成员 OpenID或成员名单。
- 所有禁言操作通过平台提供的 `sdk.qq` 调用 QQ 官方 OpenAPI。
